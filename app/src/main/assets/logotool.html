Boot animation loader

Edit logo boot MTK (logo.img) & buat boot animation. Jalan offline, tidak ada yang diunggah.

100% Offline • Client-Side

1Muat logo.img

Wajib: muat logo.img ASLI dari HP-mu dulu. Format, jumlah gambar, resolusi, dan ukuran file dipakai persis agar tidak bootloop.

2Ganti & simpan

Pilih foto untuk logo boot:

Gambar lain (animasi/ikon pengisian baterai) tidak disentuh. Bisa juga ganti satuan di kotak di bawah.

Galeri gambar

Pratinjau tiap gambar di dalam logo.img. Tekan Ganti untuk mengganti satu gambar saja.

1Video → Boot Animation

Langkah 1: pilih video Langkah 2: tekan tombol

Hasilnya bootanim_module.zip. Pasang lewat Magisk > Modul > Install dari penyimpanan, lalu reboot.

Opsi

Pengaturan (boleh dilewati)
Lanjutan: ganti sebagian saja (boleh dilewati)

Muat bootanimation.zip asli dari HP (/system/media atau /product/media) supaya hanya satu part yang diganti. Ukuran dan FPS otomatis mengikuti file asli.
